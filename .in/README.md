# Inbox usage

Each task is a separate `.md` file with a descriptive kebab-case name.

Use `/check` to pull tasks from the main inbox or Reminders.app.
Use `/do` to view and select tasks to work on.

When a task is finished or abandoned, move it to `.in/validate/` for human review (keep the original filename). Only a human moves items from `.in/validate/` to `.in/closed/`. Git history is the audit trail.
